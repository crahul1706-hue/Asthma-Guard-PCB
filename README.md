# Asthma Guard – ESP32 Sensor Interface PCB

## Project Overview
This project focuses on designing a PCB for the Asthma Guard system, which monitors environmental air quality using sensors connected to an ESP32 microcontroller.

## Objectives
- Interface environmental sensors with the ESP32.
- Organize sensor connections on a dedicated PCB.
- Support the development of a portable air-quality monitoring system.

## Hardware Components
- ESP32 DevKit
- MQ-135 air-quality sensor
- DHT22 temperature and humidity sensor
- PM2.5 particulate matter sensor

## Design Tools
- KiCad – schematic capture and PCB layout
- Gerber files – PCB fabrication data

## Repository Structure
- `KiCad_Project/` – KiCad schematic, PCB layout, and project settings
- `Gerber_Files/` – exported Gerber files for PCB fabrication

## Project Status
PCB design files and Gerber exports are organized in this repository.
